## 1. XEQM Labs 是什么

XEQM Labs 是一家隐私技术公司。其旗舰产品 EXIOM 是一个保护隐私的权益证明 Layer 1 网络和商业开发者平台，由全球服务节点集合运营。XEQM 是平台的访问和使用代币。

该项目延续了七年以上的社区和运营历史。EXIOM 主网的构建旨在为该社区提供一个具有可验证供应量、可预测发行计划、纯权益证明共识（无工作量证明组件）的网络。

XEQM 是原生 Layer 1 代币，未在任何其他链上代币化，非 ERC-20 或包装资产，无跨链桥。持有者直接与 EXIOM 主网交互。

### EXIOM 产品系列

**EXIOM 服务节点网络。** 主网上线。截至2026年7月，693个活跃节点，184个独立运营商。

**EXIOM 代币交换。** 允许项目将其持有者社区从旧链迁移到新链的商业产品，具有完整的密码学可审计性。试点是将 XEQ 持有者迁移至 XEQM，运行35天，每笔提交均通过带有公开 SHA256 指纹的密码学验证账本处理。

**EXIOM 私有开发者 API。** 开发中。通过结构化 API 公开网络隐私功能的开发者平台。第2阶段，活跃。

**EXIOM 隐私预言机。** 已设计，预实施。一种以隐私为先的预言机，证明私有网络数据的事实而不暴露底层来源。第3阶段。

**EXIOM RFQ 交易平台。** 开发中。基于 EXIOM API 构建的点对点场外交易平台，具有密码学结算证明。首个交易对为 XEQM/BTC。第2/3阶段。

XEQM Labs 不鼓励基于投机性价格升值购买 XEQM。

## 2. 供应来源

迁移已完成。276,917,604 XEQM 在 EXIOM 主网上发行以换取旧有持仓。该数字是2026年5月6日主网上线时的经验证初始供应量。每笔旧有存款均记录在带有 SHA256 指纹的公开账本中。所有参与交换的钱包的消费密钥均已公开。

**无自由裁量铸造。** 协议不允许临时发行或计划外铸造。

**无销毁。** 该网络的密码学架构不支持可证明的销毁。我们不会将任何钱包表示为销毁地址。

## 3. 代币经济学模型

网络每60秒产生一个新区块，向选定的服务节点奖励8.25 XEQM，每天生成11,880 XEQM。在700个活跃节点时，每个节点每天约赚取17.0 XEQM，即每月516 XEQM。

国库每天收到约17,857 XEQM。这是平台预收入阶段活跃商业软件开发团队的运营预算。

### 发行分配

| 分配 | 份额 | 目的 |
|---|---|---|
| 服务节点奖励 | 40% | 直接支付给服务节点的区块奖励 |
| 核心协议开发 | 25% | 区块链、EXIOM 平台和核心网络服务 |
| 营销和推广 | 15% | 网络可见性和采用 |
| 生态系统和社区 | 10% | 赠款、赏金、社区奖励 |
| 安全和审计 | 5% | 审计和安全审查 |
| 长期储备 | 5% | 稳定性和紧急需求 |

### EXIOM 平台费用分配

| 接收方 | 份额 |
|---|---|
| API 节点运营商 | 35% |
| XEQM Labs 国库 | 35% |
| 社区治理 | 30% |
